    Automatic refresh

    Runs in the background while Chrome is open and shows a notification with what changed. If Chrome was closed when a refresh was due, it runs the next time Chrome starts. The toolbar icon shows a red ! when the register is out of date.

    Each source has Link 1 (its main website) and any number of extra links: the exact pages that list the leaders (Pengurusan Tertinggi, Lembaga Pengarah, EXCO…) or org chart PDFs and pictures. Read this source now reads all of a source's links in one click: the extra links first, then the main website if fewer than 3 people were found. Each link shows what it gave last time.
