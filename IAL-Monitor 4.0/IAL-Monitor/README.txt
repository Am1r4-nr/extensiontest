IAL Monitor - SC Investor Alert List (Chrome extension)
=======================================================

INSTALL (one time)
1. Unzip this folder somewhere permanent, e.g. Documents\IAL-Monitor (do not delete it afterwards).
2. In Chrome go to chrome://extensions and switch on "Developer mode" (top right).
3. Click "Load unpacked" and choose the unzipped IAL-Monitor folder.
4. Pin the extension (puzzle icon > pin "IAL Monitor").

FIRST USE
- Click the icon > Open workspace > Settings.
- "Only show updates after" = the "as at" date of your latest Excel (default 22/09/2026).
- Enter your name for the check log. Save settings.

DAILY WORKFLOW (one click)
- The extension checks SC by itself every few hours while Chrome is open. When there is a new
  update it also opens the SC Investor Alert List page in a minimised window, copies Website /
  Reasons / Address for each new name, and closes it. You get a Windows notification.
- Click the notification (or the icon > Open workspace) and click "Download updated master Excel".
  The first time only, choose your master file (e.g. Investor_Alert_22_09_2026.xlsx); after that it
  is remembered and updated each time.
- Upload the downloaded Investor_Alert_DD_MM_YYYY.xlsx to KAF ID Screen.
- Rows marked red were not on the SC list page yet: click "Fill details automatically" later, or type them in.

NOTES
- The extension only reads www.sc.com.my. Nothing is sent anywhere else.
- Checks run only while Chrome is open.
- The check log (bottom of the workspace) records every check and export with date/time and name.
